COMO EJECUTAR EL PROYECTO
Coloca los archivos index.html, styles.css y README.txt dentro de la misma carpeta.
Abre la carpeta en tu computadora.
Haz doble clic sobre el archivo "index.html".
El proyecto se abrirá automáticamente en el navegador (Chrome, Edge, Firefox, etc.).

IMPORTANTE

El archivo index.html utiliza la siguiente línea para cargar el diseño:

<link rel="stylesheet" href="styles.css">

Por esta razón, index.html y styles.css deben permanecer en la misma carpeta.

DESCRIPCIÓN

El proyecto presenta un modelo conceptual y un diagrama de proceso sobre un sistema de pedidos de una tienda en línea.

El modelo incluye:

Entradas
Salidas
Variables de estado
Parámetros
Restricciones
Supuestos

El diagrama representa el proceso desde que el cliente confirma el pedido hasta la entrega, incluyendo la decisión de verificar si existe stock disponible.
